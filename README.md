# Программа, которая записывает ваши задачи (пока что открывается только через сам пайтон в IDLE или вручную в cmd







Как запустить





1. Скачать файл нажать правой кнопкой мыши по нему и выбрать edit in idle

Или

2\. Вручную через cmd указать место где лежит этот файл через команду cd пример:

cd C:\\Users\\PC\\Documents\\taskmanager.py

3.После того как вы написали эту команду напишите python taskmanager.py







Как пользоваться





1.После того как вы откроете файл через cmd или idle вы увидите список команд add read exit

2.Команда  add служит для того чтобы вы могли создать файл и записать в него что то

3.Команда read служит для того чтобы вы могли прочитать файл и увидеть что в нем написано

4.Команда exit служит для того чтобы вы могли выйти из программы
